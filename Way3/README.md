# jammerhunt —— 无线电干扰源的快速自动定位与清除（第三问 / 第四问）

2026 年全国大学生数学建模竞赛 B 题的**第三问（全向源）与第四问（定向+全向混合源）**求解程序。

机器狗从原点 `(0,0)` 出发，携带单频道测向机，在半径 1800 m 的圆盘内通过 HTTP+JSON
接口 `/enter /measure /clear /exit` 定位并清除**未知个数**（10–16 个）的干扰源，
在**确保全部清除**的前提下尽量减小虚拟耗时。

> 设计第一优先级是 **correctness（100% 全清）**，其次才是速度——本仓库的验证也围绕这一点展开。

## 快速开始

### 1）比赛入口（连真实模拟器 / 参考模拟器）

```bash
# 终端 1：启动模拟器（换成赛方地址亦可）
python -m offline_sim.run --robot-id TEAM1 --problem 3 --seed 42 --port 2026
# 终端 2：跑策略
python -m jammerhunt.main --robot-id TEAM1 --problem 3 --host 127.0.0.1 --port 2026
python -m jammerhunt.main --robot-id TEAM1 --problem 4 --host 127.0.0.1 --port 2026
```

策略看不到真值，仅自报：已清除频道数、各频道判定（有源已清 / 判无源）。
若存在“有源但未清”的频道，进程以非零码退出，便于脚本发现异常。

### 2）蒙特卡洛评测（本包虚拟世界，进程内、可复现）

```bash
python -m jammerhunt.mc --problem 3 -n 300              # 平滑误差场
python -m jammerhunt.mc --problem 4 -n 300 --field constant   # 最坏 ±1° 常数场
python -m jammerhunt.mc --problem 4 -n 50 --stress far_pair    # offline_sim 对抗案例复核
```

### 3）覆盖自检（打印两套扫描点集与完备性校验结论）

```bash
python -m jammerhunt.coverage
```

### 4）单元测试

```bash
python -m pytest tests/ -q
```

## 核心思想（详见 [思路.md](思路.md)）

1. **完备性靠“覆盖”而非运气**：源个数未知，要断言“某频道无源”，必须保证——若它真有源
   （区域内任意位置、`R_eff∈[1000,1500]` 任意、朝向任意），我的扫描点集里**至少一个能收到它**。
   - 第三问（全向）：**1-覆盖**——7 个扫描点，最坏“到最近点”距离 948 m < 1000。
   - 第四问（定向）：**3-覆盖（角度环绕）**——31 个扫描点，最坏方位缺口 168.6° < 180°，
     任何 180° 盲区都挡不住全部扫描点。
2. **交会定位 + 定位区域**：两条含 ±1° 误差的示向线，真源必落在两楔形之交内；取其最小包围圆，
   在圆心盲清；半径 ≤ 清除余量即必命中。
3. **归航精定位**：抵近 + 绕估计位置取两个近距侧点交会（交会角≈2δ），迅速把定位区域缩到清除半径内。
   两处关键鲁棒性修复见思路.md：**垂直优先建基线（过冲免疫）**、**朝已观测方向绕点（避开盲区）**。
