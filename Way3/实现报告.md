# Way3 实现报告 —— 第三问 / 第四问

> 分支：**way3**（origin/SXJM）。工作目录：`D:\George\SX\Way3\`。
> 题目：无线电干扰源的快速自动定位与清除。机器狗自原点 `(0,0)` 出发，携带单频道测向机，
> 在半径 `R=1800 m` 圆盘内，经 HTTP+JSON 接口 `/enter /measure /clear /exit`，
> 定位并清除**个数未知**（一局 10–16 个、每频道至多一个、频道 1–20）的干扰源，
> 在**确保全部清除**的前提下尽量减小虚拟耗时。
> - **第三问**：全部全向源。
> - **第四问**：全向 + 定向混合（定向源覆盖过源的 180° 半平面，方向未知）。

本报告分两部分：**（一）实现**（架构、算法、工程）与**（二）模拟器跑分**。方法学的完整推导见 [思路.md](思路.md)，用法见 [README.md](README.md)。

## 一、实现

### 1.1 设计第一原则：correctness（确保全清）优先于速度

题目要求“确保清除所有干扰源”。由于**源个数未知**，要停机并宣称“全部清除”，等价于对**每一个**没测到信号的频道断言“它确实无源”。这不能靠“扫到几个算几个”，必须有**覆盖保证**做逻辑支撑（见 1.3）。因此本实现把“100% 全清”当作硬指标，速度是其次的优化目标——跑分数据（第二部分）也据此解读。

### 1.2 模块架构

`jammerhunt` 包，**仅依赖 Python 标准库**（Python ≥ 3.9），保证正式测评环境零安装、稳定可跑：

| 模块 | 职责 |
|---|---|
| `geometry.py` | 纯几何：方位角、交会定位（cross-fix）、±1° 楔形交定位区域 + 最小包围圆、TSP 短巡回 |
| `coverage.py` | **完备性支柱**：全向 1-覆盖、定向 3-覆盖（角度环绕），含稠密网格数值校验 |
| `environment.py` | 自带忠实虚拟世界（物理 + 微秒计时），精确复现附件2 §10 计时示例 |
| `interface.py` | `World` 抽象三后端：`LocalWorld`（本包 Engine）/ `RunnerWorld`（接 offline_sim）/ `HttpWorld`（真机） |
| `agent.py` | 策略核心：覆盖扫描 → 交会定位 → 归航精定位 → 清除（三/四问统一，仅参数区分） |
| `mc.py` | 蒙特卡洛评测（本报告跑分即由它产生） |
| `main.py` | HTTP 比赛入口 |

一套 `agent` 策略通过 `World` 抽象在三种后端上运行、互不感知差异：进程内自评（最快）、
接 `offline_sim` 共享测试床做对抗复核、以及连真实模拟器的 HTTP 后端（带 `request_id` 幂等重试）。

### 1.3 核心算法

**(a) 覆盖完备性——“确保全清”的地基（`coverage.py`）**
所有覆盖按**最坏有效接收半径 `R_eff=1000`** 设计并数值校验：

- **全向（P3）1-覆盖**：区域内任意点到最近扫描点 ≤ 1000 m。构造“圆心 + 6 点环”，
  **7 个扫描点**，最坏最近距离 **948.3 m < 1000**。⟹ 全扫描点皆 `no_signal` 的频道**必然无源**。
- **定向（P4）3-覆盖（角度环绕）**：区域内任意点，其 1000 m 内扫描点“从该点看出去”的**最大方位缺口 < 180°**，
  于是任何 180° 盲区都挡不住全部扫描点。三角格裁剪得 **31 个扫描点**，最坏缺口 **168.6° < 180°**。
  （其中 12 个点位于半径 1800 之外——接口限制是每坐标 `|x|,|y|≤2×10⁶`，非圆盘，故合法且必要。）

**(b) 交会定位 + 定位区域（`geometry.py`）**
两条含 ±1° 误差的示向线，其 ±1° 楔形之**交**是一个凸四边形，**真源必在其中**。取该四边形的**最小包围圆** `(圆心, r)`：在圆心 `/clear`，只要 `r ≤ 20 m`（清除半径）即**盲清必中**。区域半径 ≈ `(d₁+d₂)·sin1°/sinθ`——距离越近、交会角 `θ` 越大，区域越小。

**(c) 归航精定位（`agent.py`）**
围绕估计位置取**两个近距侧点**做交会（交会角≈2δ、距离小 ⟹ 区域迅速缩小），逐轮收半径。两处关键鲁棒性修复（决定 P4 定向源能否稳定清除）：

- **垂直优先建基线（过冲免疫）**：只有 1 条示向时，**垂直于方位**偏移取第二点——绝不越过源（量程仅由 `d` 增至 `√(d²+L²)`，两侧至少一侧仍在覆盖半平面内）。避免“沿方位前进越过源、落入定向源盲区”的漏清。
- **朝已观测方向绕点（避盲区）**：绕点方向取“所有观测点相对 est 方向的圆均值”（必在覆盖半平面内），而非机器狗当前位置方向（TSP 巡回后可能恰在盲区侧）。

**(d) 效率优化**（在确保全清之后）：扫描点/待清目标用最近邻+2-opt 排短巡回；某频道定位够准（<30 m）后剪枝、不再重复测；已清满 16 源立即停机；坚持近距交会而非与 900 m 外扫描点配对（远配对 ±1°≈±16 m 恰卡清除半径边界）。

### 1.4 工程与测试

- `tests/`：**88 项 pytest 全绿**——几何、虚拟世界（含 §10 计时金标准 `[105,111,194,199]`）、覆盖完备性、端到端全清。
- `environment.py` 用**微秒整数**累计时间，避免浮点漂移，并经单测校验精确复现附件2 §10 计时序列。

## 二、模拟器跑分

### 2.1 评测口径

用 `jammerhunt.mc` 在**本包忠实虚拟世界（LocalWorld）**上跑蒙特卡洛：案例由固定种子可复现随机生成（策略看不到真值），逐局判定是否“全清”，并统计**定位-清除虚拟时间**。两类误差场：

- `smooth`：平滑 ±1° 误差场（贴近题面“误差由地点决定”的一般情形）；
- `constant`：全场恒为 +1° 的**最坏偏置**场（±1° 误差鲁棒性上界压力测试）。

> **首要指标是全清成功率**；虚拟时间为其次的“得分”参考，仅统计成功局。

### 2.2 跑分结果（本包 LocalWorld）

| 问题 | 误差场 | 局数 | **全清成功率** | 策略异常 | 均值 vt (s) | P50 | P90 | Max |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 第三问 | smooth | 200 | **100.00%** | 0 | 5186.9 | 5131.5 | 6016.6 | 7764.0 |
| 第三问 | constant(±1°最坏) | 100 | **100.00%** | 0 | 5246.4 | 5257.3 | 6018.0 | 7144.0 |
| 第四问 | smooth | 200 | **100.00%** | 0 | 9985.8 | 9972.0 | 10428.3 | 11733.5 |
| 第四问 | constant(±1°最坏) | 100 | **100.00%** | 0 | 10012.5 | 10007.4 | 10415.4 | 11145.6 |

**读数：**

- **全清率 100%（全部 600 局），策略零异常。** 这是本方案最重要的结论——无论平滑场还是最坏 ±1° 常数场，第三、第四问都**稳定全清**。
- **最坏误差场几乎不掉分：** constant 场相较 smooth 场，均值仅升 ~1%（P3 5187→5246，P4 9986→10013），且全清率不变。说明“±1° 楔形交定位区域 + 盲清必中”对误差**有几何级的鲁棒性**，而非靠运气。
- **P4 慢于 P3 约一倍：** 定向源需 31 点 3-覆盖（vs 全向 7 点 1-覆盖），扫描巡回更长，故 P4 均值 ~10000 s、P3 ~5200 s——这是“确保定向源无遗漏”的必要代价。
- **时间分布集中：** P4 的 P90 (10415) 与均值 (9986) 很接近、Max 仅 11734，无长尾发散，说明策略耗时可预测、无偶发“卡住空扫”。

### 2.3 独立复核

- **offline_sim 共享测试床（对抗案例）：** 通过 `RunnerWorld` 把同一策略投喂给独立实现的 `offline_sim.harness`，在随机 + **全部对抗压力型**（min_reff、edge_cluster、tiny_cluster、collinear、far_pair、max_count，及 P4 的 dir_outward / dir_boundary / dir_evasive；并把我方扫描点喂给生成器专挑覆盖缝隙布源）上复核——全部 100% 全清。
- **HTTP 端到端：** 用真实 socket 服务子进程跑完整一局，`/exit` 后揭示真值，与策略已清频道逐一核对——全部 PASS。
- 连同 §2.2，累计**约 3000 局全部 100% 全清**。

### 2.4 复现命令

```bash
python -m jammerhunt.mc --problem 3 -n 200 --seed 5000                 # P3 smooth
python -m jammerhunt.mc --problem 3 -n 100 --seed 7000 --field constant # P3 最坏场
python -m jammerhunt.mc --problem 4 -n 200 --seed 6000                 # P4 smooth
python -m jammerhunt.mc --problem 4 -n 100 --seed 8000 --field constant # P4 最坏场
python -m jammerhunt.mc --problem 4 -n 40  --seed 9000 --stress far_pair # 对抗复核
python -m pytest tests/ -q                                             # 88 项单测
```

## 三、结论

Way3 分支以**覆盖完备性**为地基、**交会定位 + 定位区域盲清必中**为核心、**近距归航 + 两处几何鲁棒性修复**为保障，在模拟器上对第三、第四问均取得 **100% 全清**（含最坏 ±1° 误差场与对抗案例），耗时分布集中无长尾。方案仅依赖标准库、可复现、并有 88 项单测与三通道独立验证支撑。
